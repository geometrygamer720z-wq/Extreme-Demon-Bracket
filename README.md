# Extreme Demon Bracket

A web-based 1v1 Elo ranking and tournament bracket system for Geometry Dash Extreme Demons.

## Features
- **1v1 Elo Mode:** Head-to-head matchups with dynamic Elo rating updates and live standings.
- **Bracket Cup Mode:** 8-level elimination bracket progressing through Quarterfinals, Semifinals, and Finals.
- **Level Cards:** Displays creator, verifier, song, and thumbnail preview for each demon.

## Deployment
Hosted as a static site via GitHub Pages (`index.html`).
